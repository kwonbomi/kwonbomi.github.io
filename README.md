# Bomi Kwon Academic Website

This is a standalone academic website. It does not contain or expose your research code.

## Edit first
- Replace `Bomi_Kwon_CV.pdf` whenever your CV changes.
- Update KICS status after acceptance.
- Add Google Scholar later if you want.
- Optional: replace the CSS illustrations with figures from your actual papers.

## Easiest hosting: GitHub Pages
1. Create a repository named `YOURUSERNAME.github.io`.
2. Upload `index.html`, `styles.css`, `Bomi_Kwon_CV.pdf`, and `assets/`.
3. Settings → Pages → Deploy from branch → main / root.
4. Your site will be `https://YOURUSERNAME.github.io`.

Your research repos can remain private. This website repo contains only the website itself.

## If you want the website repository private
Use Vercel, Netlify, or Cloudflare Pages connected to a private repo.
